# CaseLab ML — ДЗ №3

Решение практических заданий по CNN, transfer learning и сегментации.

## Запуск

Ноутбуки рассчитаны на запуск в Google Colab.

Рекомендуется использовать GPU:
**Среда выполнения → Сменить среду выполнения → T4 GPU**

После выбора GPU запустить:
**Runtime → Run all**

Необходимые датасеты скачиваются автоматически.

## Структура

- `06_cnn_classification/assignment.ipynb` — CNN-классификация и эксперименты.
- `07_cnn_transfer_segmentation/assignment.ipynb` — transfer learning и сегментация.
